# Escalation template (Tier 1 to Tier 2)

Paste into the ticket as a private follow-up before reassigning. Tier 2 should never have to repeat a check you already did.

```
ESCALATION: [ticket number] [short title]
Impact:        [who is affected, how many, can they work?]
Priority:      [current priority and why]
Symptoms:      [exact error messages, when it started, what changed]
Already tried: [each step and its result]
  1.
  2.
Evidence:      [screenshots, logs, event IDs, test results]
Suspected cause: [your best guess, or "unknown"]
Requester told: [what you told them and the expected next update time]
```
